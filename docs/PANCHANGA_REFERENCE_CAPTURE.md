# Panchanga golden-reference capture

This directory is generated by `scripts/capture-panchanga-reference.ts` in the active TypeScript source repository.

## Capture

Run from the repository root:

```bash
bun install
bun run scripts/capture-panchanga-reference.ts
```

The script calls only the active TypeScript Panchanga engine. It never calls Kotlin and never invents expected values. Each JSON fixture includes the source commit, engine path, Astronomy Engine version, exact scenario inputs, and the complete returned Panchanga payload.

## Current first-pass matrix

- Ten cities across India, Europe, North America, and Asia-Pacific.
- Three seasonal dates for each city.
- Amanta/Purnimanta comparison probes for Bhopal.
- All coordinate-selection modes exposed by the active TypeScript type.
- One historical lunar-month probe, without presuming its Adhika Masa classification.

The first pass is a reproducible baseline, not exhaustive edge-case coverage. Transition-adjacent vectors, no-rise/no-set conditions, timezone-change boundaries, and confirmed Adhika/Kshaya Masa cases remain separate follow-up work.

## GitHub Actions

Run **Capture Panchanga Golden References** manually from Actions. Download the `panchanga-golden-reference-v1` artifact and review the manifest and fixtures before importing them into the Android repository.

Never update expected values from Kotlin output. A source-engine update must produce a new, provenance-stamped capture and an explicit review.
