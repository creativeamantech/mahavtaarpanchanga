# D1 — Rashi Chart (राशि चक्र)

## 1. Purpose & Scope
The fundamental birth chart (Janma Kundali / Rashi Chakra). Represents the physical incarnation, physical body, constitution, health, longevity, and foundational life structure.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 3-4 (*Shodashavargadhyaya*).
- **Other References**: *Phaladeepika* (Ch. 3), *Brihat Jataka* (Ch. 1), *Saravali* (Ch. 3).

## 3. Calculation Convention
Each sign spans exactly $30^\circ$. A planet's D1 position is determined directly by its Nirayana (sidereal) longitude.

## 4. Formula & Algorithm
```typescript
const normLon = longitude % 360;
const signIndex = Math.floor(normLon / 30); // 0 (Aries) to 11 (Pisces)
const degreeInSign = normLon % 30;          // 0° to 30°
```
