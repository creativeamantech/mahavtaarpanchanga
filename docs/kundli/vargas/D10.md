# D10 — Dashamsha Chart (दशांश चक्र)

## 1. Purpose & Scope
Governs career, profession, livelihood (*vritti*), professional achievements, status, power, government recognition, social standing, and 10th house karma (*mahat-phala*).

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 15-16.
- **Verse Excerpt**:
  > *दशांशेशाश्च विषमे स्वाद् भाग्यात् समे स्मृताः।*
  > "In odd signs, dashamsha counting begins from the sign itself; in even signs, from the 9th sign (Bhagya) from it."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 10 equal parts of $3^\circ$ each.
- In **Odd Signs** (Aries, Gemini, Leo, Libra, Sagittarius, Aquarius):
  - Count starts from the sign itself: $\text{sign} + \text{part} \pmod{12}$.
- In **Even Signs** (Taurus, Cancer, Virgo, Scorpio, Capricorn, Pisces):
  - Count starts from the 9th sign from it: $\text{sign} + 8 + \text{part} \pmod{12}$.
- **Deities**: The 10 Digpalas (directional guardians):
  1. Indra (East)
  2. Agni (South-East)
  3. Yama (South)
  4. Nirriti (South-West)
  5. Varuna (West)
  6. Vayu (North-West)
  7. Kubera (North)
  8. Ishana (North-East)
  9. Brahma (Zenith / Upwards)
  10. Ananta (Nadir / Downwards)

## 4. Formula & Algorithm
```typescript
const arcSpan = 3.0; // 3°
let part = Math.floor(degInSign / arcSpan);
if (part > 9) part = 9;

const isOddSign = signIndex % 2 === 0; // 0=Aries (odd)
const startOffset = isOddSign ? 0 : 8; // 8 = 9th sign from itself
const dashamshaSignIndex = (signIndex + startOffset + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```
