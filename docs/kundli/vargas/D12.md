# D12 — Dwadashamsha Chart (द्वादशांश चक्र)

## 1. Purpose & Scope
Governs parents (father, mother), ancestry, heritage, lineage (*kula*), past-life connection to family, and genetic/karmic inheritances.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 17-18.
- **Verse Excerpt**:
  > *द्वादशांशस्य गणना तत्तद्राशेः प्रजायते।*
  > "The counting of the Dwadashamsha always begins from that very sign itself."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 12 equal parts of $2^\circ 30'$ ($2.5^\circ$) each.
- In every sign, the counting starts from the sign itself:
  $$\text{D12 Sign} = (\text{signIndex} + \text{part}) \pmod{12}$$
- **Deities**: Cyclically repeating across the 12 parts:
  1. Ganesha
  2. Ashwini Kumaras
  3. Yama
  4. Sarpa
  (repeated 3 times: $4 \times 3 = 12$).

## 4. Formula & Algorithm
```typescript
const arcSpan = 2.5; // 2°30'
let part = Math.floor(degInSign / arcSpan);
if (part > 11) part = 11;

const dwadashamshaSignIndex = (signIndex + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```
