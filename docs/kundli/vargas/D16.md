# D16 — Shodashamsha / Kalamsa Chart (षोडशांश चक्र)

## 1. Purpose & Scope
Governs conveyances, vehicles (*vahana*), pleasures, luxuries, mental ease, general happiness and sorrows (*sukha-dukha*), accidents, and journey-related security (4th house higher octave: $4 \times 4 = 16$).

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 19-20.
- **Verse Excerpt**:
  > *चरे मेषात् स्थिरे सिंहात् चापात् द्वितनुषु क्रमात्।*
  > "For movable signs, start from Aries; for fixed signs, from Leo; for dual signs, from Sagittarius."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 16 equal parts of $1^\circ 52' 30''$ ($1.875^\circ$) each.
- **Movable Signs (Chara)** (Aries, Cancer, Libra, Capricorn):
  - Starts from Aries (0): $\text{sign} = (0 + \text{part}) \pmod{12}$.
- **Fixed Signs (Sthira)** (Taurus, Leo, Scorpio, Aquarius):
  - Starts from Leo (4): $\text{sign} = (4 + \text{part}) \pmod{12}$.
- **Dual Signs (Dvisvabhava)** (Gemini, Virgo, Sagittarius, Pisces):
  - Starts from Sagittarius (8): $\text{sign} = (8 + \text{part}) \pmod{12}$.
- **Deities**: Brahma, Vishnu, Shiva, Surya (repeated 4 times: $4 \times 4 = 16$).

## 4. Formula & Algorithm
```typescript
const arcSpan = 30 / 16; // 1.875°
let part = Math.floor(degInSign / arcSpan);
if (part > 15) part = 15;

const modality = signIndex % 3; // 0 = Chara, 1 = Sthira, 2 = Dvisvabhava
let startSign = 0;
if (modality === 0) startSign = 0; // Aries
else if (modality === 1) startSign = 4; // Leo
else startSign = 8; // Sagittarius

const shodashamshaSignIndex = (startSign + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```
