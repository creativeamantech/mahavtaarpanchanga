# D2 — Hora Chart (होरा चक्र)

## 1. Purpose & Scope
Represents accumulated wealth (*dhana*), treasury (*kosha*), financial stability, family lineage assets, capacity to earn, and speech.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 5-6.
- **Verse Excerpt**:
  > *विषमे प्रथमः सूर्यो द्वितीयश्चन्द्रमः स्मृतः।*
  > *समे तु प्रथमो चन्द्रो द्वितीयो भास्वरः स्मृतः ॥*
  > "In odd signs, the first half belongs to the Sun (Leo), the second half to the Moon (Cancer). In even signs, the first half belongs to the Moon (Cancer), and the second to the Sun (Leo)."

## 3. Calculation Convention
- Each rashi is divided into 2 equal parts of $15^\circ$ each.
- In **Odd Signs** (Aries, Gemini, Leo, Libra, Sagittarius, Aquarius):
  - $0^\circ \text{ to } 15^\circ$: Sun's Hora $\to$ Leo (Simha, index 4).
  - $15^\circ \text{ to } 30^\circ$: Moon's Hora $\to$ Cancer (Karka, index 3).
- In **Even Signs** (Taurus, Cancer, Virgo, Scorpio, Capricorn, Pisces):
  - $0^\circ \text{ to } 15^\circ$: Moon's Hora $\to$ Cancer (Karka, index 3).
  - $15^\circ \text{ to } 30^\circ$: Sun's Hora $\to$ Leo (Simha, index 4).

## 4. Formula & Algorithm
```typescript
const isOddSign = signIndex % 2 === 0; // 0-indexed: 0=Aries (odd sign)
const part = Math.floor(degInSign / 15); // 0 (0-15°) or 1 (15-30°)

let horaSignIndex: number;
if (isOddSign) {
  horaSignIndex = part === 0 ? 4 : 3; // 4=Leo, 3=Cancer
} else {
  horaSignIndex = part === 0 ? 3 : 4; // 3=Cancer, 4=Leo
}
const degreeInVarga = ((degInSign % 15) / 15) * 30;
```

## 7. Known Ambiguities
- **Parashara vs. Kashinatha/Kalyanavarma Hora**: Some modern software (e.g. Jagannatha Hora) supports an alternative 12-sign cyclic Hora attributed to Kalyanavarma (*Saravali*). However, Parashara in BPHS specifies the Sun/Moon (Cancer/Leo) hora as the canonical standard for Shodashavarga. The canonical engine implements Parashara's classical standard.
