# D20 — Vimshamsha Chart (विंशांश चक्र)

## 1. Purpose & Scope
Governs spiritual progress, religious inclinations, mantra siddhi, upasana, devotion (*bhakti*), divine blessings, occult practices, and esoteric spiritual evolution.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 21-22.
- **Verse Excerpt**:
  > *चरे मेषात् स्थिरे चापात् द्वितनौ सिंहात् प्रजायते।*
  > "For movable signs, start from Aries; for fixed signs, from Sagittarius (Chapa); for dual signs, from Leo (Simha)."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 20 equal parts of $1^\circ 30'$ ($1.5^\circ$) each.
- **Movable Signs (Chara)** (0, 3, 6, 9):
  - Starts from Aries (0): $\text{sign} = (0 + \text{part}) \pmod{12}$.
- **Fixed Signs (Sthira)** (1, 4, 7, 10):
  - Starts from Sagittarius (8): $\text{sign} = (8 + \text{part}) \pmod{12}$.
- **Dual Signs (Dvisvabhava)** (2, 5, 8, 11):
  - Starts from Leo (4): $\text{sign} = (4 + \text{part}) \pmod{12}$.
- **Deities**: 20 divine Shaktis/forms:
  1. Kali, 2. Gauri, 3. Jaya, 4. Vijaya, 5. Vimala, 6. Mangala, 7. Jwalamukhi, 8. Tara, 9. Bhadrakali, 10. Shulini, 11. Shubha, 12. Dooti, 13. Karali, 14. Kampini, 15. Bhairavi, 16. Vasudha, 17. Padma, 18. Jwala, 19. Mohini, 20. Shripa.

## 4. Formula & Algorithm
```typescript
const arcSpan = 1.5; // 1°30'
let part = Math.floor(degInSign / arcSpan);
if (part > 19) part = 19;

const modality = signIndex % 3; // 0 = Chara, 1 = Sthira, 2 = Dvisvabhava
let startSign = 0;
if (modality === 0) startSign = 0; // Aries
else if (modality === 1) startSign = 8; // Sagittarius
else startSign = 4; // Leo

const vimshamshaSignIndex = (startSign + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```

## 7. Known Ambiguities
- Note the difference between D16 and D20 starting signs:
  - D16: Movable $\to$ Aries, Fixed $\to$ Leo, Dual $\to$ Sagittarius.
  - D20: Movable $\to$ Aries, Fixed $\to$ Sagittarius, Dual $\to$ Leo.
