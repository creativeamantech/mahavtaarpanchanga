# D24 — Chaturvimshamsha / Siddhamsha Chart (चतुर्विंशांश चक्र)

## 1. Purpose & Scope
Governs higher knowledge, education, learning capacity, academic achievements, memory, wisdom (*vidya*), research, and artistic/intellectual accomplishments (*siddhis*).

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 23-24.
- **Verse Excerpt**:
  > *सिद्धांशेशा विषमे सिंहात् समे कर्कात् प्रकीर्तिताः।*
  > "For Siddhamsha (D24), counting begins from Leo in odd signs, and from Cancer in even signs."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 24 equal parts of $1^\circ 15'$ ($1.25^\circ$) each.
- In **Odd Signs** (Aries, Gemini, Leo, Libra, Sagittarius, Aquarius):
  - Starts from Leo (4): $\text{sign} = (4 + \text{part}) \pmod{12}$.
- In **Even Signs** (Taurus, Cancer, Virgo, Scorpio, Capricorn, Pisces):
  - Starts from Cancer (3): $\text{sign} = (3 + \text{part}) \pmod{12}$.
- **Deities**: Cyclically repeating through 4 divine principles:
  1. Skanda
  2. Parashudhara
  3. Anala (Agni)
  4. Vishwakarma
  (repeated 6 times: $4 \times 6 = 24$).

## 4. Formula & Algorithm
```typescript
const arcSpan = 1.25; // 1°15'
let part = Math.floor(degInSign / arcSpan);
if (part > 23) part = 23;

const isOddSign = signIndex % 2 === 0; // 0=Aries (odd)
const startSign = isOddSign ? 4 : 3; // Leo (4) or Cancer (3)

const chaturvimshamshaSignIndex = (startSign + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```
