# D27 — Saptavimshamsha / Bhamsa / Nakshatramsha Chart (सप्तविंशांश चक्र)

## 1. Purpose & Scope
Governs physical stamina, physiological constitution, subconscious inclinations, inner hidden strengths and weaknesses (*bala-abala*), vulnerabilities, and subtle immunities.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 25-26.
- **Verse Excerpt**:
  > *मेषात् कर्कात् तुलात् नक्रात् भभागेषु विचिन्तयेत्।*
  > "In Bhamsa (D27), count from Aries, Cancer, Libra, and Capricorn respectively for Fire, Earth, Air, and Water signs."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 27 equal parts of $1^\circ 06' 40''$ ($\frac{30^\circ}{27} \approx 1.1111111111^\circ$) each.
- The starting sign is determined by the sign's elemental triplicity (the four cardinal/movable signs):
  - **Fire signs** (Aries, Leo, Sagittarius): Starts from Aries (0).
  - **Earth signs** (Taurus, Virgo, Capricorn): Starts from Cancer (3).
  - **Air signs** (Gemini, Libra, Aquarius): Starts from Libra (6).
  - **Water signs** (Cancer, Scorpio, Pisces): Starts from Capricorn (9).
- Formula: $\text{sign} = (\text{startSign} + \text{part}) \pmod{12}$.
- **Deities**: The 27 Nakshatras/deities cyclically.

## 4. Formula & Algorithm
```typescript
const arcSpan = 30 / 27; // 1.1111111111°
let part = Math.floor(degInSign / arcSpan);
if (part > 26) part = 26;

const elementIndex = signIndex % 4; // 0=Fire, 1=Earth, 2=Air, 3=Water
let startSign = 0;
if (elementIndex === 0) startSign = 0; // Aries
else if (elementIndex === 1) startSign = 3; // Cancer
else if (elementIndex === 2) startSign = 6; // Libra
else startSign = 9; // Capricorn

const saptavimshamshaSignIndex = (startSign + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```
