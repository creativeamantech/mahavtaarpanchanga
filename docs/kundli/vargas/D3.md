# D3 — Drekkana Chart (द्रेष्काण चक्र)

## 1. Purpose & Scope
Governs siblings, co-borns (*bhratri*), vitality, energy, physical courage, enterprise, initiative, third house matters, and the nature of death (when analyzing 22nd Drekkana / *Kharesha*).

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 7-8.
- **Verse Excerpt**:
  > *स्वभवनात् पञ्चमाच्च नवमाच्चैव ते विदुः।*
  > "Know the three Drekkanas as falling in the sign itself, the 5th from it, and the 9th from it respectively."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 3 equal parts of $10^\circ$ each.
- **Part 1 ($0^\circ \text{ to } 10^\circ$)**: Sign itself (1st house from itself, $+0$).
- **Part 2 ($10^\circ \text{ to } 20^\circ$)**: 5th sign from it ($+4$).
- **Part 3 ($20^\circ \text{ to } 30^\circ$)**: 9th sign from it ($+8$).
- **Sub-rulers / Deities**:
  - Part 1: Narada (Deva / Sattva)
  - Part 2: Agastya (Manushya / Rajas)
  - Part 3: Durvasa (Rakshasa / Tamas)

## 4. Formula & Algorithm
```typescript
const part = Math.floor(degInSign / 10); // 0, 1, or 2
let shift = 0;
if (part === 1) shift = 4;      // 5th sign
else if (part === 2) shift = 8; // 9th sign

const drekkanaSignIndex = (signIndex + shift) % 12;
const degreeInVarga = ((degInSign % 10) / 10) * 30;
```

## 7. Known Ambiguities
- **Parashari vs. Jagannath / Somanatha Drekkana**: There are alternative drekkanas in Jaimini astrology (e.g. Parivritti-traya Drekkana, Somanatha Drekkana). Parashara's trinal (1st-5th-9th) Drekkana is the universally acknowledged standard in Vedic astrology.
