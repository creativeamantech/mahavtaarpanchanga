# D30 — Trimshamsha Chart (त्रिंशांश चक्र)

## 1. Purpose & Scope
Governs evils, misfortunes, diseases (*arishta*), deep psychological afflictions, enemies, moral character flaws, hidden vulnerabilities, and dangers. Critical in female horoscopy (*Stri Jataka*) for examining chastity, disposition, and marital happiness.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 27-28.
- **Verse Excerpt**:
  > *वह्न्यर्किजीवज्ञसिता विषमे पञ्च पञ्च च।*
  > *अष्टसप्त च पञ्चैते व्यत्यस्ताः समराशिषु ॥*
  > "In odd signs: Mars (5°), Saturn (5°), Jupiter (8°), Mercury (7°), and Venus (5°). In even signs, the order is reversed: Venus (5°), Mercury (7°), Jupiter (8°), Saturn (5°), and Mars (5°)."

## 3. Calculation Convention
Unlike other charts, Trimshamsha does NOT divide $30^\circ$ into equal fractions. Instead, it assigns 5 unequal planetary bounds (ruler degrees) to the 5 planets (Mars, Saturn, Jupiter, Mercury, Venus). The luminaries (Sun and Moon) own no Trimshamsha bounds.

### In Odd Signs (विषम राशि - Aries, Gemini, Leo, Libra, Sagittarius, Aquarius):
| Range | Span | Ruling Planet | Assigned Sign (D30) | Sign Index |
|---|---|---|---|---|
| $0^\circ \text{ to } 5^\circ$ | $5^\circ$ | Mars (Mangala) | Aries (Mesha) | 0 |
| $5^\circ \text{ to } 10^\circ$ | $5^\circ$ | Saturn (Shani) | Aquarius (Kumbha) | 10 |
| $10^\circ \text{ to } 18^\circ$ | $8^\circ$ | Jupiter (Guru) | Sagittarius (Dhanu) | 8 |
| $18^\circ \text{ to } 25^\circ$ | $7^\circ$ | Mercury (Budha) | Gemini (Mithuna) | 2 |
| $25^\circ \text{ to } 30^\circ$ | $5^\circ$ | Venus (Shukra) | Libra (Tula) | 6 |

### In Even Signs (सम राशि - Taurus, Cancer, Virgo, Scorpio, Capricorn, Pisces):
| Range | Span | Ruling Planet | Assigned Sign (D30) | Sign Index |
|---|---|---|---|---|
| $0^\circ \text{ to } 5^\circ$ | $5^\circ$ | Venus (Shukra) | Taurus (Vrishabha) | 1 |
| $5^\circ \text{ to } 12^\circ$ | $7^\circ$ | Mercury (Budha) | Virgo (Kanya) | 5 |
| $12^\circ \text{ to } 20^\circ$ | $8^\circ$ | Jupiter (Guru) | Pisces (Meena) | 11 |
| $20^\circ \text{ to } 25^\circ$ | $5^\circ$ | Saturn (Shani) | Capricorn (Makara) | 9 |
| $25^\circ \text{ to } 30^\circ$ | $5^\circ$ | Mars (Mangala) | Scorpio (Vrishchika) | 7 |

## 4. Formula & Algorithm
```typescript
const isOddSign = signIndex % 2 === 0; // 0=Aries (odd)
let d30SignIndex: number;
let boundStart = 0;
let boundSpan = 5;

if (isOddSign) {
  if (degInSign < 5) {
    d30SignIndex = 0; boundStart = 0; boundSpan = 5; // Aries (Mars)
  } else if (degInSign < 10) {
    d30SignIndex = 10; boundStart = 5; boundSpan = 5; // Aquarius (Saturn)
  } else if (degInSign < 18) {
    d30SignIndex = 8; boundStart = 10; boundSpan = 8; // Sagittarius (Jupiter)
  } else if (degInSign < 25) {
    d30SignIndex = 2; boundStart = 18; boundSpan = 7; // Gemini (Mercury)
  } else {
    d30SignIndex = 6; boundStart = 25; boundSpan = 5; // Libra (Venus)
  }
} else {
  if (degInSign < 5) {
    d30SignIndex = 1; boundStart = 0; boundSpan = 5; // Taurus (Venus)
  } else if (degInSign < 12) {
    d30SignIndex = 5; boundStart = 5; boundSpan = 7; // Virgo (Mercury)
  } else if (degInSign < 20) {
    d30SignIndex = 11; boundStart = 12; boundSpan = 8; // Pisces (Jupiter)
  } else if (degInSign < 25) {
    d30SignIndex = 9; boundStart = 20; boundSpan = 5; // Capricorn (Saturn)
  } else {
    d30SignIndex = 7; boundStart = 25; boundSpan = 5; // Scorpio (Mars)
  }
}
const degreeInVarga = ((degInSign - boundStart) / boundSpan) * 30;
```

## 7. Known Ambiguities
- Some modern Western sidereal or alternative software attempts an arithmetic $1^\circ$ division for D30 ($30 \times 1^\circ$). In classical Vedic astrology, this is strictly incorrect. Parashara, Varahamihira, Kalyanavarma, and Mantreshwara all unanimously define the unequal planetary bounds given above.
