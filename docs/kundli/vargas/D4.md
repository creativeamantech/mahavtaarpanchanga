# D4 — Chaturthamsha / Turyamsha Chart (चतुर्थांश चक्र)

## 1. Purpose & Scope
Governs fortune, immovable property (*bhumi*), real estate, home, domestic happiness, buildings, conveyances, fixed assets, and inheritances.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 9-10.
- **Verse Excerpt**:
  > *स्वभवनात् केन्द्रगाः स्युश्चतुर्थांशपयो नृप।*
  > "The lords of the four parts in Chaturthamsha are in the Kendras (1st, 4th, 7th, and 10th) from the sign itself."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 4 equal parts of $7^\circ 30'$ ($7.5^\circ$) each.
- **Part 1 ($0^\circ \text{ to } 7.5^\circ$)**: Sign itself ($+0$).
- **Part 2 ($7.5^\circ \text{ to } 15.0^\circ$)**: 4th sign from it ($+3$).
- **Part 3 ($15.0^\circ \text{ to } 22.5^\circ$)**: 7th sign from it ($+6$).
- **Part 4 ($22.5^\circ \text{ to } 30.0^\circ$)**: 10th sign from it ($+9$).
- **Deities**: Sanaka, Sanandana, Sanatkumara, Sanatana (the 4 Kumaras).

## 4. Formula & Algorithm
```typescript
const part = Math.floor(degInSign / 7.5); // 0, 1, 2, or 3
const shift = part * 3; // 0, 3, 6, 9
const chaturthamshaSignIndex = (signIndex + shift) % 12;
const degreeInVarga = ((degInSign % 7.5) / 7.5) * 30;
```
