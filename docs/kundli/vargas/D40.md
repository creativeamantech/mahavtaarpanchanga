# D40 — Khavedamsha / Chatvarimshamsha Chart (खवेदांश चक्र)

## 1. Purpose & Scope
Governs auspicious and inauspicious events, general auspiciousness (*shubhashubha phala*), maternal heritage, maternal family karma, and subtle strengths of planets.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 29-30.
- **Verse Excerpt**:
  > *खवेदांशे च विषमे मेषात् समे तुलात् स्मृताः।*
  > "In Khavedamsha (D40), counting begins from Aries in odd signs, and from Libra in even signs."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 40 equal parts of $0^\circ 45'$ ($0.75^\circ$) each.
- In **Odd Signs** (Aries, Gemini, Leo, Libra, Sagittarius, Aquarius):
  - Starts from Aries (0): $\text{sign} = (0 + \text{part}) \pmod{12}$.
- In **Even Signs** (Taurus, Cancer, Virgo, Scorpio, Capricorn, Pisces):
  - Starts from Libra (6): $\text{sign} = (6 + \text{part}) \pmod{12}$.
- **Deities**: Cyclically repeating across 4 principles:
  1. Vishnu
  2. Chandra
  3. Marichi
  4. Tvashita
  (repeated 10 times: $4 \times 10 = 40$).

## 4. Formula & Algorithm
```typescript
const arcSpan = 0.75; // 45 arcminutes
let part = Math.floor(degInSign / arcSpan);
if (part > 39) part = 39;

const isOddSign = signIndex % 2 === 0; // 0=Aries (odd)
const startSign = isOddSign ? 0 : 6; // Aries (0) or Libra (6)

const khavedamshaSignIndex = (startSign + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```
