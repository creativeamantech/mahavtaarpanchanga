# D45 — Akshavedamsha Chart (अक्षवेदांश चक्र)

## 1. Purpose & Scope
Governs moral conduct, character purity (*charitra*), integrity, general well-being (*sarva-shubhashubha*), and spiritual cleanliness.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 31-32.
- **Verse Excerpt**:
  > *चरे मेषात् स्थिरे सिंहात् चापात् द्वितनुषु क्रमात्।*
  > "For movable signs, start from Aries; for fixed signs, from Leo; for dual signs, from Sagittarius."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 45 equal parts of $0^\circ 40'$ ($\frac{30^\circ}{45} = \frac{2^\circ}{3} \approx 0.6666666667^\circ$) each.
- The starting sign is determined by the sign's modality (identical trinal start points to D16):
  - **Movable Signs (Chara)** (Aries, Cancer, Libra, Capricorn): Starts from Aries (0).
  - **Fixed Signs (Sthira)** (Taurus, Leo, Scorpio, Aquarius): Starts from Leo (4).
  - **Dual Signs (Dvisvabhava)** (Gemini, Virgo, Sagittarius, Pisces): Starts from Sagittarius (8).
- Formula: $\text{sign} = (\text{startSign} + \text{part}) \pmod{12}$.
- **Deities**: Cyclically repeating across the holy Trinity:
  1. Brahma (Creator)
  2. Shiva (Transformer)
  3. Vishnu (Preserver)
  (repeated 15 times: $3 \times 15 = 45$).

## 4. Formula & Algorithm
```typescript
const arcSpan = 30 / 45; // 0.6666666667° (40 arcminutes)
let part = Math.floor(degInSign / arcSpan);
if (part > 44) part = 44;

const modality = signIndex % 3; // 0 = Chara, 1 = Sthira, 2 = Dvisvabhava
let startSign = 0;
if (modality === 0) startSign = 0; // Aries
else if (modality === 1) startSign = 4; // Leo
else startSign = 8; // Sagittarius

const akshavedamshaSignIndex = (startSign + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```
