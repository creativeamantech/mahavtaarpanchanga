# D7 — Saptamsha Chart (सप्तांश चक्र)

## 1. Purpose & Scope
Governs children, progeny, lineage, grandchildren, reproductive vitality, creative output, and fruits of marriage (*santati*).

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 11-12.
- **Verse Excerpt**:
  > *विषमे स्वात् समे चैव कलत्राद् गणना भवेत्।*
  > "In odd signs, counting begins from the sign itself. In even signs, counting begins from the 7th house (Kalatra) from it."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 7 equal parts of $\frac{30^\circ}{7} \approx 4^\circ 17' 08.57''$ ($4.2857142857^\circ$).
- In **Odd Signs** (Aries, Gemini, Leo, etc.):
  - Count starts from the sign itself: $\text{sign} + \text{part} \pmod{12}$.
- In **Even Signs** (Taurus, Cancer, Virgo, etc.):
  - Count starts from the 7th sign from it: $\text{sign} + 6 + \text{part} \pmod{12}$.
- **Deities**: The 7 divine fluids/oceans:
  1. Kshara (Salt ocean)
  2. Ksheera (Milk ocean)
  3. Dadhi (Curd ocean)
  4. Ghrita (Ghee ocean)
  5. Ikshu-rasa (Sugarcane juice)
  6. Madhu (Honey)
  7. Shuddha-jala (Pure water)

## 4. Formula & Algorithm
```typescript
const arcSpan = 30 / 7;
let part = Math.floor(degInSign / arcSpan);
if (part > 6) part = 6;

const isOddSign = signIndex % 2 === 0; // 0=Aries (odd)
const startOffset = isOddSign ? 0 : 6;
const saptamshaSignIndex = (signIndex + startOffset + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```
