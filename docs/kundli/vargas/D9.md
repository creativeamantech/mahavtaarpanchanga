# D9 — Navamsha Chart (नवांश चक्र)

## 1. Purpose & Scope
The most crucial divisional chart in Vedic astrology alongside D1. Governs *Dharma*, marriage, spouse, matrimonial harmony, inner potential, soul direction (*atman*), spiritual aptitude, and the strength of planets in the second half of life. A planet that is strong in D1 but weak in D9 loses real fruition.

## 2. Classical Source
- **Text**: Brihat Parashara Hora Shastra (BPHS), Chapter 6, Verses 13-14.
- **Verse Excerpt**:
  > *चरे स्वात् स्थिरे धर्मात् द्विशरीरे च धीभतः।*
  > "For movable signs, count from the sign itself; for fixed signs, from the 9th sign (Dharma); for dual signs, from the 5th sign (Dhi)."

## 3. Calculation Convention
- Each rashi of $30^\circ$ is divided into 9 equal parts of $3^\circ 20'$ ($3.3333333333^\circ$) each, mapping to the 108 padas of the 27 Nakshatras.
- **Movable Signs (Chara)** (Aries 0, Cancer 3, Libra 6, Capricorn 9):
  - Starts from the sign itself ($+0$).
- **Fixed Signs (Sthira)** (Taurus 1, Leo 4, Scorpio 7, Aquarius 10):
  - Starts from the 9th sign from it ($+8$).
- **Dual Signs (Dvisvabhava)** (Gemini 2, Virgo 5, Sagittarius 8, Pisces 11):
  - Starts from the 5th sign from it ($+4$).
- **Equivalent Element Counting**:
  - Fire signs (Aries, Leo, Sag) $\to$ start at Aries (0).
  - Earth signs (Taurus, Virgo, Cap) $\to$ start at Capricorn (9).
  - Air signs (Gemini, Libra, Aqu) $\to$ start at Libra (6).
  - Water signs (Cancer, Scorpio, Pisces) $\to$ start at Cancer (3).

## 4. Formula & Algorithm
```typescript
const arcSpan = 30 / 9; // 3°20'
let part = Math.floor(degInSign / arcSpan);
if (part > 8) part = 8;

let startNavamsha = 0;
if ([0, 4, 8].includes(signIndex)) startNavamsha = 0; // Aries
else if ([1, 5, 9].includes(signIndex)) startNavamsha = 9; // Capricorn
else if ([2, 6, 10].includes(signIndex)) startNavamsha = 6; // Libra
else if ([3, 7, 11].includes(signIndex)) startNavamsha = 3; // Cancer

const navamshaSignIndex = (startNavamsha + part) % 12;
const degreeInVarga = ((degInSign - part * arcSpan) / arcSpan) * 30;
```
