This directory contains the authoritative mathematical, classical, and algorithmic specifications for all 16 divisional charts (Shodashavargas) defined in *Brihat Parashara Hora Shastra* (BPHS), Chapter 6.

## Varga Groups in Classical Jyotisha

In BPHS, these 16 charts are categorized into diagnostic groups:
1. **Shadvarga** (6 charts): D1, D2, D3, D9, D12, D30.
2. **Saptavarga** (7 charts): Shadvarga + D7.
3. **Dashavarga** (10 charts): Saptavarga + D4, D10, D16.
4. **Shodashavarga** (16 charts): Dashavarga + D20, D24, D27, D40, D45, D60.

In Vimshopaka Bala, Shashtiamsha (D60) receives the highest individual weightage (5 points out of 20), followed by Rashi (3.5 points) and Navamsha (3 points).
